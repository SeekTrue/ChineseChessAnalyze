## 二、功能

输入：一个中文文字记谱的 `.txt` 棋谱文件（UTF-8）。
输出 `result` 结构体：

- `boards{k}`：`10×9` 棋盘矩阵，`k=1` 为初始局面，`k=i+1` 为第 `i` 步后的局面。
  - `0`=空，`1–7` 红方（帅仕相马车炮兵），`8–14` 黑方（将士象马车炮卒）——**与原有代码棋子编号完全一致**。
- `moves(i)`：每步详情（raw / side / piece / from / to / capture / valid / err）。
- `date`：对局日期。
- `nSteps` / `nValid`：总步数 / 成功步数。
- `quality`：`nValid/nSteps`，可信度（1.0 = 完全解析成功）。
- `errors`：失败步骤的错误说明。

**坐标系**：`row=1` 黑方底线，`row=10` 红方底线；红方纵线 N → `col=10−N`，黑方纵线 N → `col=N`。

**已处理的记谱细节**：
- 黑方全角数字（如 `马８进７`）与红方中文数字（如 `马八进七`）
- 「进/退」按棋子类型区分：车炮兵帅为步数，马士相为到达纵线
- 蹩马腿、塞象眼、九宫限制、炮架规则、兵卒不过河不横走
- 「前/后/中」叠子歧义（如 `前车进一`），按同列多候选 + 目标合法性消歧

## 三、验证结果（本机 MATLAB R2018a 实测）

| 测试 | 样本 | 总步数 | 成功率 |
|---|---|---:|---:|
| 小样本 | 20 局 | 1,611 | 99.88% |
| 泛化测试 | 100 局 | 8,009 | **100%** |
| 压力测试 | 500 局 | 42,993 | **99.916%** |

500 局中仅 4 个文件（0.8%）出现错误，共 36 步，均为**早期单步走错后的状态偏移连锁**，非系统性缺陷。初始局面 22 个关键棋子位置自检全部通过。

**已知限制**：
- 极少数局面因"前/后兵"等消歧在多个同类棋子 row 相同时可能选错，导致后续连锁失败。
- 解析器不做"将死/将军"终局判定（这是下一步"从末步推断将死"要补的）。
- 遇到失败步不要紧——用 `quality` 字段过滤低质量棋局即可，不影响统计。

## 四、使用方法

```matlab
addpath('E:\程序\ChineseChessAnalyze\Matlab');
res = parseNotation('D:\棋局抓取\棋谱序列\大师对局\88025.txt');
if res.quality >= 0.99
    % 用于统计的可靠局面序列
    boards = res.boards;
end
```

批量处理示例（配合 `quality` 过滤）：

```matlab

for i = 1:numel(files)
    res = parseNotation(fullfile(files(i).folder, files(i).name));
    if res.quality < 0.99
        fprintf('跳过低质量棋局: %s (quality=%.3f)\n', files(i).name, res.quality);
        continue;
    end
    % ... 编码统计
end
```

## 六、编码说明

两个 `.m` 文件均为 **GBK 编码**，因为 MATLAB R2018a 在中文 Windows 下按系统编码（GBK）读取 `.m` 文件；若改成 UTF-8，中文字符串会乱码导致正则匹配失败。棋谱 `.txt` 本身是 UTF-8，解析器已用 `fopen(...,'n','UTF-8')` 正确处理。
