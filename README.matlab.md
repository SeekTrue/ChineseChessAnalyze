# 中国象棋认知编码分析

用 MATLAB 分析中国象棋棋谱，挖掘高频/关键的棋局结构，设计一套更适合人类记忆的分层标签编码，
以降低认知负担、提升棋力。

## 目录结构

```
.
├── Matlab/     # MATLAB 源码（13 个原始文件 UTF-8 + 2 个新解析器 GBK 编码）
└── docs/       # 架构设计、代码评估、数据盘点、解析器交付说明
```

## 理论背景

核心假设来自认知心理学的组块（chunking）理论：象棋高手的记忆优势来自对棋局结构的组块化编码，
而非天生记忆力。本项目试图从棋谱中挖掘可被当作"基本记忆单元"的结构，并生成分层标签树，
作为一套可学习、可记忆的编码系统。

## 已有代码说明

`Matlab/` 下的代码已完成"单局面分析"层面的工作，主要包括：

- **攻击范围引擎**：7 种棋子的移动/攻击范围计算（含蹩马腿、塞象眼、炮架、九宫及过河限制）
- **战术状态分析**：危 / 险 / 疲 / 困 / 串 / 双 / 游 七种状态检测
- **局面编码**：将局面压缩为 16 字符定长编码（认知编码的技术雏形）
- **可视化**：棋盘绘制、攻击范围热力图、命令行 ASCII 棋盘

代码评估与后续架构见 `docs/` 目录。

## 新增：中文记谱解析器

- `Matlab/parseNotation.m`：把中文文字记谱棋谱（如「炮二平五 马８进７」）解析为逐局面棋盘矩阵。
  处理全角数字、进退语义、蹩马腿/塞象眼/九宫/炮架、前后中叠子消歧。
  棋子编号与原代码一致（0 空 / 1-7 红 / 8-14 黑）。`result.quality` 用于过滤低质量棋局。
- `Matlab/validateParser.m`：验证脚本。

MATLAB R2018a 实测：100 局 8009 步 100% 通过；500 局 42993 步 99.916% 通过。
注意解析器等 2 个新文件为 GBK 编码（适配 R2018a 中文 Windows），与原始 13 个 UTF-8 文件不同。
